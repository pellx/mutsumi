- Export GEMINI_AUDIO_MODEL = 'gemini-3.8-flash', GEMINI_TIMING_SOURCE = 'google/gemini-3.8-flash/model-estimate-not-forced-alignment'.
- Export GEMINI_AUDIO_SCHEMA: JSON Schema for a root object with exactly transcript (string) and segments (array). Each segment has exactly text (string), units (array), emotion (string or null). Each unit has exactly text (string), granularity ('word' or 'character'), start_ms (integer or null), end_ms (integer or null). All fields required; additionalProperties:false at every object. Bounds may be null so missing capability cannot force invented numbers. This describes output estimates, not Gemini's private vocabulary token IDs.
- Export mapGeminiAudioResult(json: string, asset: AudioAsset): {ok:true,value:AnnotatedAudio}|{ok:false,error:AnalysisFailure}. Validate asset first. Parse JSON from string only; no arbitrary JS object traversal. Reject unknown keys, wrong types/empty spoken text, oversized JSON (>1 MiB), transcript >65536 code units, >256 segments, >4096 total units, unsafe/fractional/negative/reversed/out-of-clip times, inappropriate granularity (character must be one Unicode code point), lexical gaps/duplicates/mismatches. Pure result errors use static safe messages, stage:'transcription', retryable:false, codes invalid_audio/invalid_result/timing_unavailable; no raw text, cause, URL or provider message.
- Require full transcript == concatenated segment texts and each segment == concatenated unit texts after NFC, Unicode punctuation and whitespace removal ONLY. Do not transliterate names, remove symbols, change words or manufacture punctuation durations. Spoken unit text cannot be punctuation-only. For spoken output all units require positive valid bounds. Missing/null/equal bounds returns timing_unavailable; negative/reversed/out-of-range bounds invalid_result. Across ordered units require nondecreasing start_ms; allow real overlaps and pauses, do not distribute sentence durations.
- Generate deterministic local segment/observation IDs. Keep segment text/full transcript unchanged. Derive segment envelope as min start/max end of its units, marking envelope derivation in source. Units keep exact integer bounds and GEMINI_TIMING_SOURCE. Do not copy any unknown payload field into output. Emotion, when a nonempty string (<=128 code units), is an audio-model candidate, preserved at segment scope with the derived envelope and Google/model provenance. Null means unknown; no invented score and no independent unit emotion.
- Capabilities word_timing is ok for valid timed speech (Google/model). Emotion is ok iff any candidate is present; otherwise unavailable with a static reason. Prosody and sound_event remain unavailable: this prompt/schema did not assess them. Exactly empty transcript plus no segments is valid silence with no fabricated units/emotions. Reject whitespace-only transcript, nonempty transcript with empty segments, or empty transcript with speech segments.
- Run validateAnnotatedAudio on the mapped result before returning success. Never mutate inputs or fabricate timing. Do not export helpers beyond the specified public API.

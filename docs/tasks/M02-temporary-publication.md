Create ONLY apps/server/src/providers/aliyun/temporary-publication.ts in exactly ONE successful write. No cosmetic rewrites, no line-count target. No .env, real audio, provider calls, dependencies, other files or Git. Supervisor commits and assigns synthetic tests separately. Only saved-file read-back, then stop.

Implement export class AlibabaTemporaryPublication implements AudioPublicationPort, erasable TypeScript (no parameter properties/decorators). Import ports as types from ../../application/analysis-ports.js, validateAudioAsset runtime from ../../domain/annotation.ts, FILETRANS_MODEL runtime from ./filetrans-result.ts. No vendor SDKs or Node-only imports; use native fetch/FormData/Blob/crypto/AbortSignal.

Constructor options type export TemporaryPublicationOptions:
- apiKey: string; readAudio: (storageKey: string, signal: AbortSignal) => Promise<Blob>; maxBytes: number; timeoutMs: number.
- optional fetch: typeof globalThis.fetch; now: () => number; objectId: () => string. Defaults native fetch, Date.now, crypto.randomUUID; don't call networks at construction.
Use fixed approved Beijing root https://dashscope.aliyuncs.com/api/v1/uploads. Store apiKey privately (prefer # field), reject empty/CRLF key and invalid positive safe-integer limits with static configuration Error, no option values leaked. readAudio resolves opaque server-side key; no direct file path APIs or environment loading here.

publish behavior:
1. Reject invalid asset/key before reading or requesting; accept only nonempty safe opaque storage_key /^[A-Za-z0-9][A-Za-z0-9_.-]{0,127}$/ (no client paths). Reject requested model !== FILETRANS_MODEL before any read/network with code model_mismatch. Use failure objects matching AnalysisFailure (stage publication), static safe messages, no cause/body/URLs/key values. Invalid audio -> invalid_audio, cancelled -> cancelled, own deadline -> timed_out, remaining errors -> publication_failed. retryable false, caller controls explicit retries. Catch external errors, never forward their message/cause.
2. Native combined signal: caller AbortSignal and own timeout. Must race both local reader and HTTP/body waits against abort, so an injected dependency that ignores the signal cannot leave publish pending forever. Clean abort listeners/timers; distinguish caller abort from own deadline. Check before side effects and before returning; abort never returns a successful reference. No automatic retries.
3. Blob must be nonempty, <=maxBytes, type matches asset.media_type; honor model-supported file types using extensions map: audio/wav/audio/x-wav->wav, audio/mpeg->mp3, audio/flac->flac, audio/ogg->ogg, audio/mp4->m4a, audio/webm->webm, audio/aac->aac. Unsupported types -> invalid_audio, not disguised format. No format conversion: intake will verify real bytes in a later module.
4. GET upload-policy URL with action=getPolicy&model=FILETRANS_MODEL and Authorization: Bearer key, Content-Type application/json, redirect error, combined signal. Require HTTP200. Bound policy JSON download to 64KiB using Content-Length early check if present and a stream byte counter (do not buffer arbitrary body before checking). Parse JSON and validate data fields; reject malformed.
5. Fields: nonempty strings policy/signature/upload_dir/upload_host/oss_access_key_id; x_oss_object_acl exactly private; x_oss_forbid_overwrite exactly string true. expire_in_seconds and max_file_size_mb are documented number OR decimal numeric string; explicitly parse only that union to finite positive numbers, no general coercion. Require integer expiry, safe integer byte limit derived from MiB; remember policy response acquisition time + TTL and check again immediately before upload. Distinguish this TTL from media lifetime. Blob within min(configured limit, policy max bytes).
6. upload_host must HTTPS on *.oss-cn-beijing.aliyuncs.com, no credentials/port/query/hash and pathname /; reject other schemes, deceptive suffixes and redirect follow. upload_dir a safe slash-separated object prefix with no empty/dot/dotdot segments, backslashes or control chars. Generated objectId must nonempty safe filename characters /^[A-Za-z0-9_-]{1,128}$/; use it plus proper extension, never user's filename.
7. Native FormData fields exactly OSSAccessKeyId, Signature, policy, x-oss-object-acl, x-oss-forbid-overwrite, key, success_action_status=200; file LAST as Blob with generated filename. POST to policy host with redirect error and signal. DO NOT add API Authorization or manual multipart Content-Type. Require HTTP200; cancel/consume response body without unbounded buffering. No raw upload/policy data persisted or logged.
8. Return {uri: 'oss://'+objectKey, model:FILETRANS_MODEL, expires_at_ms: policyAcquiredAt+48*60*60*1000, transport:'oss-resource'}. Expiry is a conservative prototype estimate, not upload credential TTL. No delete guarantee or cross-model reuse. Injected now must be safe finite epoch milliseconds; fail safely on invalid clock instead of emitting invalid expiry.

Expose only class/options; keep utilities private. No analysis-job submission, polling or result mapping. Report file/path, actual read-back and limitations; do not claim live upload verification or unrun tests.

Tests must cover:

- Valid Chinese result, two sentences, Unicode single-character units AND a multi-character word, measured times, gap/overlap allowed, punctuation stored in sentence/full transcript but no separate fabricated punctuation unit. Verify exact times, derived durations, granularity, stable local segment/observation IDs, model/provider/timing provenance, unchanged caller input and deterministic output. Verify full transcript uses provider text rather than a fabricated concatenation.
- Sentence emotion retained exactly, unknown label retained, no invented score. Missing labels produce no observations; no labels at all marks emotion unavailable. Partially labeled sentences keep existing observations and emotion ok without inventing labels for missing sentences. Prosody/sound_event unavailable. Empty-string transcript with empty sentences is successful silence distinct from missing timing. Frozen and null-prototype JSON records remain supported.
- Nonempty speech absent/null/empty words or absent/null begin/end on a word -> timing_unavailable. No placeholder zero intervals returned. Zero is VALID measured start if end>0: add a positive success case, not a rejection.
- Negative/reversed/equal/fractional/unsafe/nonfinite/out-of-duration sentence or unit times -> invalid_result; positive asset-valid out-of-parent unit -> invalid_result. String dates/numeric strings not coerced. Invalid asset -> invalid_audio, even when raw is otherwise bad. Output errors have safe static messages, stage transcription, retryable false, no raw payload/URLs/credentials/IDs included.
- Wrong/null/primitive root, absent transcripts, zero/multiple transcripts, wrong channel, missing/wrong transcript text, nonempty transcript without sentences, empty transcript with speech sentences, whitespace transcript/segment/unit text, invalid containers/elements, wrong emotion/word punctuation types -> invalid_result. Extra ordinary vendor fields ignored and do not leak into annotation.
- Sparse arrays, extra array properties, custom prototypes, non-enumerable properties and symbols rejected. Getters at root/array index/sentence/word/unknown record field remain uninvoked; verify counter after mapping.
- Bounds: 10001 sentences and >100000 words rejected without truncation; total words across multiple sentences also bounded. Use compact fixtures sharing immutable sample records rather than enormous copied text. Accepted bound itself can be checked if practical; don't make slow benchmarks.

Use grouped/parameterized cases with understandable diagnostics. Do not inspect private mapper functions or mirror implementation line counts. Do not loosen assertions to fit a source defect. Report actual totals, failing fixture inputs if any, exact changed path and proposed commit message. A passing synthetic mapper suite is not live ASR or full M02 acceptance.

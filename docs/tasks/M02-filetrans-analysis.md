# M02d — Asynchronous Alibaba analysis adapter

Official DeepSeek fallback through Codex CLI. Read AGENTS.md, required architecture/flow, docs/aliyun-asr-integration.md and this brief. Create ONLY apps/server/src/providers/aliyun/filetrans-analysis.ts in ONE successful write, no subsequent edits/compaction. No line target. No providers/.env/private data/packages/Git. Saved-file read-back only; supervisor type-checks and tests separately. Prefer a direct readable state flow and a few real helpers, not placeholder/dead plumbing or a wrapper for every predicate.

Export class AlibabaFiletransAnalysis implements AudioAnalysisPort and type FiletransAnalysisOptions. Erasable TS, no parameter properties/decorators/SDKs/Node-only imports. Import runtime validateAudioAsset from ../../domain/annotation.ts, mapFiletransResult/FILETRANS_MODEL from ./filetrans-result.ts; import ports/domain types using erased type-only imports. It must not depend on temporary-publication.ts, upload files, load credentials or infer emotions.

Options: apiKey:string, timeoutMs:number, pollIntervalMs:number, maxPolls:number, maxResultBytes:number; optional fetch:typeof globalThis.fetch, now:()=>number, sleep:(ms:number,signal:AbortSignal)=>Promise<void>. Defaults native fetch/Date.now/native abort-aware timer. Validate config using safe static Error, no option values; timeout/interval positive safe ints <=2147483647, maxPolls positive <=10000, maxResultBytes positive <=16MiB. Key nonempty no control characters, private # field. No requests at construction.

analyze(audio, remote, {signal}) steps:
1. Validate asset first. Reject mismatched remote.model before network with model_mismatch. Validate remote reference: transport oss-resource requires oss:// plus nonempty safe slash-separated object key (no dots/dotdot/empty components, controls, backslashes, query/hash/userinfo); https requires public Alibaba OSS hostname (bucket.oss-REGION.aliyuncs.com, no -internal endpoint), HTTPS, no userinfo or alternate port; signed query allowed. Unknown transport/invalid URI -> invalid_audio. expires_at_ms null means unspecified; otherwise safe integer epoch and strictly later than valid injected now, else invalid_audio. Never return/log reference/signature/URI.
2. Shared own deadline plus caller cancellation bounds EVERY fetch, body read and polling sleep, including dependencies ignoring signals. Dispose listeners/timers, observe losing promises and release late response bodies best-effort; cancellation cleanup never awaited unbounded. Caller aborted -> cancelled, own deadline/poll budget exhausted -> timed_out; no success after abort. External exceptions become safe failure at the appropriate stage, not Error.name-based cancellation.
3. Submit exactly ONCE to https://dashscope.aliyuncs.com/api/v1/services/audio/asr/transcription with POST JSON {model:FILETRANS_MODEL,input:{file_url:remote.uri},parameters:{channel_id:[0],enable_itn:false,enable_words:true}}. Headers Authorization Bearer key, Content-Type application/json, X-DashScope-Async enable, plus X-DashScope-OssResourceResolve enable only for oss-resource. redirect error. Require HTTP200 and bounded parsed JSON (64KiB). No automatic retry even on ambiguous timeout/HTTP429. Missing/malformed task_id or submission/status payload -> submission_failed. Task id /^[A-Za-z0-9_-]{1,128}$/.
4. Initial output.task_status: PENDING/RUNNING continue polling; SUCCEEDED can download immediately with returned result; FAILED/UNKNOWN -> provider_failed. Other/missing status -> submission_failed. Poll GET https://dashscope.aliyuncs.com/api/v1/tasks/{encodedTaskId}, Authorization header, redirect error, same signal, bounded JSON64KiB. Wait configured interval under deadline before each GET. maxPolls caps GET count even if injected sleep resolves immediately and microtasks would otherwise starve timers. PENDING/RUNNING continue, SUCCEEDED finish, FAILED/UNKNOWN -> provider_failed; unrecognized/malformed output/status or returned task_id mismatch -> invalid_result. Do not inspect task-level end_time date as audio timing.
5. For success require output.result.transcription_url. Only expected result host dashscope-result-bj.oss-cn-beijing.aliyuncs.com, no userinfo/alternate port/hash. Signed query preserved. Official examples use http; upgrade only this approved host to HTTPS before GET (do not modify signed query/path otherwise); https accepted directly. Reject other scheme/host or missing URL with invalid_result before result fetch. Credentials NEVER forwarded to result host: no Authorization/ASR headers. redirect error, same deadline, maxResultBytes stream bound and Content-Length early bound; HTTP200 required. Parse JSON then mapFiletransResult(raw,audio). Return mapped value or throw mapper's safe AnalysisFailure unchanged. No raw provider JSON/URL logged or persisted here.
6. All failures thrown as plain AnalysisFailure with stage transcription, safe STATIC message, retryable false, no cause/raw payload/keys/URLs. invalid asset/ref -> invalid_audio, submission request/JSON errors -> submission_failed, polling HTTP/connection/provider FAILED/UNKNOWN -> provider_failed, malformed poll/download/mapped results -> invalid_result unless mapper returns timing_unavailable. All cancellation/timeout paths retain their own codes. Every nonconsumed response body is released best-effort on early errors, stream limit/abort, and late settlement.

Do not weaken required timing: spoken text without measured units remains a mapper failure; silence allowed. Reuse understood deadline/bounded-stream behavior patterns but don't copy the publication-specific policy/forms or create dead abstractions. Report path/read-back/limitations; no compile/tests/live-ASR claims.

Primary protocol checked 2026-10-01: https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference (async submit, tasks poll and signed result JSON). Live upload has passed separately on a synthetic Chinese sample, but this adapter is not yet live-verified and implementing model must never open data/.runtime private QA references.

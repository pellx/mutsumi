Official DeepSeek authorized fallback. Read AGENTS.md, required architecture/flow, docs/tasks/M02-temporary-publication.md and this brief. Create ONLY tests/acceptance/temporary-publication.test.mjs in ONE successful write; absolutely no later compaction/formatting. No line-count target. No source/spec/package edits, Git, provider calls or .env. Use node:test/assert and native Response/ReadableStream/Blob/FormData with synthetic fixtures, import adapter .ts. Public behavior; no private helpers. Run once with node --test; if spawn blocked, in-process once then report/stop. Supervisor independently runs checks and handles fixes.

Use injected readAudio/fetch/now/objectId and a clearly fake key 'test-api-key', never an sk-like fixture. All network requests must be synthetic fetches (constructor always provided mock fetch). No real media or outbound calls.

Cover these behaviors, grouped/parameterized as appropriate:
- Happy path: one local read, GET approved policy with exact model query and API Authorization, one POST to OSS host ROOT; no bearer or manual Content-Type on POST, redirect error on both, shared abort signal. FormData exact policy fields, generated key prefix/id.wav, file LAST, file bytes/MIME correct. Return exact oss-resource reference/model/media expiry = policy-response arrival+48h (not credential TTL), inputs unchanged. No ASR job calls/retries.
- Numeric policy fields accepted as documented number or decimal string; invalid numeric booleans, scientific strings, nonfinite/negative/zero/fractional TTL and unsafe byte/epoch values fail safely. Policy size limit smaller than config rejects Blob before POST, and config size limit rejects before policy request.
- Invalid asset/unsafe storage key/unsupported MIME/empty or MIME-mismatched Blob -> invalid_audio without inappropriate network. Wrong model -> model_mismatch with zero reads/calls. Invalid constructor key/limits/functions -> static config Error, key value not leaked.
- Reject unapproved HTTP host, credentials, alternate ports, deceptive suffix, query/hash/path; malformed upload_dir including empty/trailing slash/dot/dotdot/backslash/control. Invalid objectId rejected. Require private ACL and forbid_overwrite='true', fields present/nonempty.
- Expired upload policy and backwards clock reject before POST. For slow body: native ReadableStream with highWaterMark:0 prevents pre-pull; capture current clock on response arrival, advance clock during actual body pull by TTL, ensure credential expiry prevents POST. No fake extension of TTL by parsing body later. Invalid clock before consuming the policy body must also release/cancel that body, not leave an unread response.
- HTTP errors, thrown fetch/readAudio exceptions, invalid JSON, missing data/fields -> static publication_failed, no provider body/key/URL/cause leaking and retryable false. Check response body release on early non-200 status errors, oversized Content-Length, streamed >64KiB with no length, invalid clock and read abort. Do not weaken cleanup assertions to fit a source bug.
- Pre-aborted caller => cancelled, no side effects. Mid-read/mid-fetch/mid-body caller cancellation => cancelled and no POST; own deadline => timed_out even when readAudio/fetch/body ignores signals. Bound tests with outer node:test timeout but use adequate margins (e.g. own20ms, outer2000ms), no performance benchmark. An unrelated external Error named TimeoutError remains publication_failed.
- Cleanup must not hang if stream cancel() returns a never-settling promise. Late fetch response arriving after caller abort is cancelled/released best effort and cannot produce success. All failures are plain safe AnalysisFailure fields only, stage publication. Verify no unhandled rejection from a losing promise that rejects after abort.

No test assertion changes to hide a source issue. If a real defect appears, report exact scenario, expected/observed behavior, leave source untouched and stop. Report actual totals, path, failing cases and proposed commit text. Synthetic upload acceptance cannot establish actual cloud upload or whole M02 success.

Provider JSON shape (not task-status response): {transcripts: [{channel_id: 0, text: string, sentences: [{begin_time: integer, end_time: integer, text: string, emotion?: string, words: [{begin_time: integer, end_time: integer, text: string, punctuation?: string}]}]}]}. Transcript text and each segment text must be strings. Model configuration requests channel_id=[0], enable_words=true, enable_itn=false.

Requirements:
- Validate asset first with validateAudioAsset, return invalid_audio safely if invalid. Map malformed payload to invalid_result, except nonempty spoken text with absent/empty words or missing word timing -> timing_unavailable. Failure stage transcription, safe static messages, retryable false. Do not include raw input, URLs, IDs or metadata in errors. Do not throw on supported malformed JSON-oriented input.
- Read only ordinary own enumerable data-property records and dense ordinary arrays; reject getters/custom prototypes/symbols/extra array keys without invoking accessors. Additional ordinary record data fields can be ignored. Arbitrary hostile Proxy objects are outside scope. Reject missing fields, null, wrong primitive types and nonfinite times without coercion.
- Bound processing: no more than 10000 sentences, no more than 100000 words in total; return invalid_result if exceeded. Do not truncate.
- Audio-relative begin/end must be safe integer 0<=begin<end<=asset.duration_ms and each word must fit its parent. Never use task-level date strings, clamp values, invent timings or average sentence duration. Segment IDs seg-0...; observation IDs emotion-0...; values deterministic. Preserve sentence order.
- Full transcript text uses provider transcript.text. Empty transcript text + empty sentences is valid silence with no observations, word_timing ok (requested capability worked with no speech); contradictory nonempty sentences on empty transcript or nonempty transcript with zero sentences -> invalid_result. Pure-whitespace speech text is invalid_result (except empty-string silence); reject blank sentence/word text. Do not require exact concatenation because provider punctuation/spacing may differ.
- Each sentence becomes a segment with timing source 'aliyun:qwen3-asr-flash-filetrans'. Each provider word becomes a TimedUnit with same measured bounds. Keep word.text exactly; punctuation is retained only in segment/transcript text, never a fabricated timed unit. If word.text consists of exactly one Unicode letter or number use granularity character; otherwise word. This denotes text-unit size, not independent per-character emotion or perfect character precision. Do not split multi-character words.
- Nonempty emotion strings become observations with kind emotion, provider 'aliyun', model FILETRANS_MODEL, the sentence interval and segment_ids pointing to the segment. Preserve labels exactly, including unknown labels, no invented numeric score. Missing/null/empty emotion fields produce no observation. A non-string non-null emotion field is invalid_result. Emotion capability ok only if all nonempty sentences have valid emotion labels (or successful silence); otherwise unavailable with safe reason but retain any observed labeled sentences. NOTE domain observations require emotion capability ok, so when some sentences are unlabeled, capability must remain ok if at least one label was actually observed; missing individual sentence emotion stays absent. For non-silent results with no labels at all mark emotion unavailable. Never fabricate neutral.
- word_timing ok provenance aliyun/FILETRANS_MODEL. prosody and sound_event unavailable, explicit unsupported reasons. Segment and observation provenance consistent. No emotion inference from text.
- Validate constructed annotation with validateAnnotatedAudio; any failure -> invalid_result safe static message. Preserve caller inputs unchanged.
